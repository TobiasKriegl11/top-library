# top-library

Library App

This is a simple book library built with HTML, CSS, and JavaScript.

You can:

Add new books
Mark books as read or unread
Remove books
View all books in a responsive grid
What I learned

While building this project, I practiced:

Creating objects with constructors
Using arrays to store data
Working with prototypes and methods
Adding event listeners
Creating and modifying HTML elements with JavaScript
Using data-* attributes
Using .find() and .findIndex()
Building responsive layouts with CSS Grid
Using form validation and dialog elements
